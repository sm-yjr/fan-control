## 目标判断

候选实现已覆盖主动散热的关键机制：持续 CPU 负载前馈、CPU/GPU 独立温升预测、热浸、冷却驻留，以及默认 38°C、可外部两点校准的体感目标。此前单纯温度曲线不足以满足提前介入目标，已增加独立 Adaptive 模式。体感设置用于该模式，系统自动仍是安全初始状态，固定 RPM 和曲线保留独立高级调节。

目前可确认策略在模拟中先于严重热压力介入。实际持续性能优于 Apple 默认控制、键盘表面更舒适，以及可正式推出的结论尚缺实机与分发证据。完整门槛见 [产品验收清单](rust-product-acceptance.md)。
