# Fan Control 0.7.0

本版本将主窗口、菜单栏浮窗与曲线编辑器全面迁移至 **GPUI（`gpui-pre` 0.3.14 + `runtime_shaders`）** 与 **GPUI Kit（`gpui-component` 0.11.0）**，在 macOS 26+ 上挂载原生 `NSGlassEffectView` Liquid Glass 材质（macOS 14–15 自动降级为 `NSVisualEffectView`），并修复了首次开启“登录时启动”时 `SMAppService` 初始状态误判的问题。底层 `fan-core` 控制算法、配置格式与 helper 协议 9 保持兼容不变。

## 主要变化

- **GPUI + GPUI Kit 与原生 Liquid Glass**：全面重写主窗口（860×640 可缩放分栏布局）、菜单栏悬浮玻璃面板（400×560）与曲线编辑器模态窗口；在 macOS 26+ 上将原生 `NSGlassEffectView` 置于 GPUI 透明 Metal 图层之下呈现实时玻璃材质，在 macOS 14–15 上平滑回退为 `NSVisualEffectView`；启用 `runtime_shaders` 保持纯 Command Line Tools 命令行构建能力，并保留 `accesskit_macos` 辅助功能支持。
- **macOS Tahoe 风格界面重构**：主窗口采用半透明侧边栏（顶部圆形状态头图、5 枚彩色渐变圆角 Lucide SVG 导航图标、底部轻量“恢复系统自动”按钮）与 `< | >` 历史导航胶囊；各页面统一采用带顶部微高光描边的分组卡片、GPUI Kit 弹簧动画开关、全胶囊分段控件、柔和红/蓝/玻璃胶囊按钮与 `(i)` 说明脚注；设置页提供 4 枚蓝色玻璃缩略图预览瓷砖用于实时切换菜单栏显示模式。
- **Metal GPU 加速图表与表盘**：使用 GPUI Metal 绘图重绘 180° 转速弧形表盘（含末端微光圆点）、10 分钟温度趋势面积图与交互式温控曲线画布。
- **修复“登录时启动”开关失效**：修复 macOS 上首次注册前 `SMAppService.mainAppService.status` 返回 `SMAppServiceStatusNotFound`（3）导致读取报错和开启失败的问题，首次未注册时正确按关闭处理并允许正常执行 `register()`。
- **工程与依赖升级**：Rust Workspace MSRV 同步升级至 1.92.0，移除被替代的旧 AppKit 视图层文件，保留薄 AppKit 桥接负责 `NSStatusItem`、Sparkle 动态加载、`SMAppService` 与原生系统对话框，并扩展 `fan-licenses` 已审核 SPDX 许可证集合。

## 升级提示

helper 协议保持版本 9，配置路径 `~/.config/fan-control/config.json` 及既有曲线、智能散热偏好与校准数据完全兼容；已安装协议 9 helper 的设备升级后无需重新授权安装。
