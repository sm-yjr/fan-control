# Fan Control 0.3.0 候选

新增智能散热偏好：原生滑杆提供 21 档，从更安静到更凉快，默认 0 保持既有策略。此次为新增可配置功能，候选采用 minor 版本 0.3.0；正式发行仍待验收门禁完成。

## 功能与兼容

- 草稿在“保存并应用”后提交，持久化成功、worker 接受并发布配置后反馈确认；失败有提示，重复保存被阻止，还原从已接受配置恢复。
- 偏好不依赖外部表面温度校准，仅影响智能模式；保留手动/曲线模式、自定义曲线、热历史、待确认动作和冷却驻留。
- 日常需求最多调整 ±8 个百分点，偏置约 10 秒平滑过渡。安静端减幅在 80–90°C 逐步撤销，紧急保护、校准高端下界、硬件上下限和失效回退独立执行。
- 旧 Swift/Rust 配置缺失偏好时使用 0。越界整数、null 或错误 JSON 类型只恢复偏好字段并给出警告，保留其余有效配置；配置版本保持 2，helper 协议保持 8。
- 目标仍为 macOS 14+、Apple Silicon arm64。未替换用户安装的 App 或 helper，不扩大机型实测声明。

## 验证与发布状态

独立本地离线检查已通过：rustfmt、workspace Clippy（告警视为失败）、100 项核心测试、71 项 fan-app 单元测试。候选提交完整 CI 应覆盖 macOS 14/15、Rust 1.85.1、模拟平台测试、签名打包、隔离中英文 UI smoke、Sparkle runtime 与 DMG 校验；实际结果以该提交的 CI 为准。

真实键盘与 VoiceOver、深浅色、真实窗口关闭重开、风扇控制/归还与睡眠恢复、实际旧版更新安装仍待验收。内部温度不能当作机壳表面实测，安静度、机壳温度或性能改善没有实机对照证据。

依照 AGENTS.md 和 Rust 产品验收清单，本候选未正式发布、未推送发布标签，也未更新稳定 appcast。完成必要验收和 main CI 后，才可通过既有 Release 工作流生成 Developer ID 签名、公证 App/DMG 和 Ed25519 appcast。
