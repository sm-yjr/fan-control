# Fan Control 0.3.1

修复智能散热偏好更新后的状态误报，并将当前选择从滑杆端点行移到独立区域。本次为 0.3.0 的补丁更新。

## 修复

- 原始需求为 5%、更凉快偏好修正为 6.52% 时，界面不再误报等待交还系统。状态提示与控制器共用低需求前提，同时检查原始/修正需求、持续负载、温升趋势和体感需求，并计入独立安全下界。
- 界面没有控制器的驻留计时，因此低需求提示仅说明等待持续冷却，不推断转速方向或宣称已经交还。未知、过期和非有限需求保留等待数据提示；控制器计时、静音确认、RPM 条件及安全策略保持原样。
- helper 失联或写入失败后，交还尚未确认的 worker 状态单独提供给 UI。全局提示和智能页优先显示“交还系统尚未确认”，暂停界面接管入口，不把热安全介入或旧 Forced/目标读数当作主动控制证据。未改变 worker 的交还重试与写入暂停行为。
- 偏好卡片两端只显示“更安静／更凉快”，当前选择与恢复默认按钮在下方独立区域。中英文采用相同的原生分组布局，当前选择可换行；21 档、默认 0、保存流程均保留。无关曲线和图例未改。

## 验证与限制

本地最终修复检查通过：rustfmt、workspace Clippy（告警视为失败）、101 项 core、77 项 app、10 项许可和 67 项平台模拟测试；5 项实机探针默认忽略。回归覆盖所有 21 档、释放边界、持续负载/温升/体感/安全下界、数据不可用与非有限值，以及交还未确认、热安全和确认恢复的状态区别。隔离中英文原生 UI 检查覆盖重复调整、恢复默认、模拟保存失败/失联、重复保存和页面重建及最小现有 620pt 页面布局断言。

用户明确跳过本次桌面测试。真实截图、深浅色视觉观察、键盘/VoiceOver 和真实窗口关闭重开仍未验收；布局断言不构成视觉验收。真实风扇控制/回读、睡眠恢复、旧版实际更新和噪声/表面温度/性能对照也未新增证据。未安装、替换或启动用户当前 App/helper，未操作真实 SMC；不宣称完整成熟产品验收。

支持范围仍为 macOS 14+、Apple Silicon arm64。配置版本 2、helper 协议 8、Sparkle 版本与更新源保持原样。本次沿既有 Release 工作流完成 Developer ID 签名、公证、Ed25519 appcast 与公开 DMG；正式结果以 [v0.3.1 Release](https://github.com/sm-yjr/fan-control/releases/tag/v0.3.1) 和对应 CI 的实际产物核验为准。

安全报告入口见 [SECURITY.md](../../SECURITY.md)，许可证与第三方材料继续随包提供。
