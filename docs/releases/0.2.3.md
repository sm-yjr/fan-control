# Fan Control 0.2.3

本版本修复 macOS 14+、Apple Silicon 菜单栏应用的温度详情展示与传感器语义问题。

## 修复

- 温度详情改用原生 AppKit `NSTableView`，复用可见行，定时刷新不重建列表并保留滚动位置。
- 支持按名称及原始 SMC key 搜索，提供中英文名称展示；名称与 key 分行显示，长名称保留完整提示。
- 补充 M1–M5 的 CPU/GPU、存储、内存、供电、气流、虚拟温度和热余量展示语义；未确认项目保留原始 key。
- 补充中英文传感器名称和详情页提示，并随包保留 iSMC GPLv3 来源与许可证。
- 既有 CPU/GPU/System 控制成员、控制语义、SMC 写入路径和 helper 协议 8 保持不变；本轮没有风扇写入或已安装 helper 替换。

## 覆盖与验证

- `./script/test_rust.sh`：rustfmt、Clippy 与 235 项 tests 通过。
- CLT + Rust 构建、shell 语法检查、本地 arm64 ad-hoc 签名打包和 Sparkle runtime 检查通过。
- 中英文隔离 `--ui-smoke` 均在详情页验证 1000 个模拟读数、8 次跨位置滚动累计 15 个单元格、最新/过期读数、滚动位置、搜索命中、空结果和清空搜索。
- 只读样本覆盖率：本机 M1 Ultra 从 17/316 提升到 243/316；仓库 M4 fixture 从 24/159 提升到 153/159。样本没有执行风扇写入，覆盖率不代表完整型号实机验收。

## 兼容范围与限制

- 目标为 macOS 14+、Apple Silicon arm64；不宣称 Intel 或 universal 支持。
- 连续触控板滚动体感、VoiceOver 实际读序、深浅色实际外观仍待验证；M5 热余量沿用既有有效温度过滤，0–1°C 不显示，全范围显示尚未验证。管理员安装、真实 SMC 写入和睡眠—唤醒也仍待验证。
- 本地 ad-hoc 签名和候选检查不等同于 Developer ID、公证、Gatekeeper 或更新安装验收。正式发布产物由发布工作流生成并单独核验。
