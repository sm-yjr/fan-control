# Fan Control 0.6.0

本版本完成全量原生 AppKit UI/UX 视觉与交互重构，统一菜单栏、主窗口、曲线编辑器与桌面小组件的设计语言，并新增状态栏可选实时读数与磨砂侧边栏可缩放主窗口。底层散热控制算法、安全策略、配置格式与 helper 协议保持不变。

## 主要变化

- **统一语义设计系统**：建立统一主题令牌与分层圆角卡片组件（动态解析系统浅/深色、高对比度与强调色），全界面统一圆角等宽数字、语义图标胶囊、渐变面积趋势图与 180° RPM 弧形表盘。
- **状态栏可选实时读数**：在“设置 → 通用”中新增菜单栏显示选项，支持“仅图标 / 图标与芯片温度 / 图标与最高转速 / 图标、温度与转速”四档实时切换（默认保持仅图标，偏好存放在用户偏好中，不改动 `config.json`）。
- **菜单栏面板精炼**：改为分层卡片排布并按当前散热方式条件展开控件（仅“智能散热”显示 21 档散热偏好，仅“自定义”显示固定速度滑块与曲线入口），保持全状态刷新零尺寸抖动。
- **磨砂侧边栏可缩放主窗口**：主窗口重构为原生 `NSSplitViewController` 磨砂侧边栏布局，支持自由缩放与窗口位置记忆，切换 5 个页面不再跳动高度；侧边栏底部常驻状态摘要与一键“恢复系统自动”按钮。“概览”页升级为仪表盘总控台，支持直接切换散热方式与查看 180° 实时表盘。
- **风扇、智能散热与温度详情页精修**：“风扇”页统一为 180° RPM 表盘与 4 段模式选择器，目标转速与硬件确认状态直接可见；“智能散热”页的 21 档散热偏好统一为松手即保存并回显确认，高级“键盘体感目标与两点校准”收纳至原生可折叠区域；“温度详情”页传感器列表随窗口拉伸，新增按分组筛选与“按最热”排序。
- **现代化曲线编辑器**：以 Auto Layout 与就地状态更新重写曲线编辑器，切换预设、增删控制点、更换控制依据和撤销均不再销毁重建窗口；图表新增渐变填充、实时交叉点与拖拽坐标胶囊。
- **桌面小组件对齐与双语补全**：小组件对齐高温语义色温与趋势图端点高光，补齐所有新增中英文词条。

## 升级提示

helper 协议保持版本 9，配置路径 `~/.config/fan-control/config.json` 与已有风扇模式、自定义曲线、智能散热偏好和校准数据完全兼容；已安装协议 9 helper 的设备升级后无需重新授权安装。
