# Fan Control 0.6.1

本版本专注打磨主窗口侧边栏与设置页的原生 AppKit 视觉和排布细节，对齐现代 macOS 系统设置风格，同时保持底层控制算法、配置格式与 helper 协议不变。

## 主要变化

- **设置页视觉重构**：采用 14pt 圆角柔和填充卡片、0.5pt 细分隔线与单行设置项排布；顶部新增 4 枚可视化的“菜单栏显示”蓝底玻璃感缩略图卡片，选中项提供双层系统强调色边框与实时文字预览。
- **行内交互精简**：“登录时启动”采用原生 `NSSwitch`，“界面语言”改为无边框行内下拉选择器，“诊断信息 / 使用帮助 / 关于”统一右侧 `>` 箭头交互，并在卡片下方补充 `(i)` 说明脚注。
- **侧边栏与顶栏对齐**：侧边栏顶部升级为圆形应用状态头图，5 项导航采用 22×22 彩色渐变圆角图标且与顶部图标保持同一左基线，选中态使用半透明浅灰圆角胶囊并保持浅/深色清晰文字对比，底部精简为轻量“恢复系统自动”按钮；主窗口右侧移除生硬的通栏分隔线，并补全动态系统窗口背景画布。
- **跨页边距统一**：“概览”“风扇”“智能散热”“温度详情”与“设置”统一为 28pt 水平留白，同步补全中英文词条与浅/深色设置页离屏渲染验证。

## 升级提示

helper 协议保持版本 9，配置路径 `~/.config/fan-control/config.json` 及既有曲线、智能散热偏好与校准数据完全兼容；已安装协议 9 helper 的设备升级后无需重新授权安装。
