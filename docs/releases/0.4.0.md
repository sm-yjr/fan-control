# Fan Control 0.4.0

菜单栏采用紧凑原生仪表盘：芯片温度与 10 分钟趋势、实测 RPM 半圆仪表、散热方式和 21 档偏好。单风扇居中，双风扇并列；名称与转速范围来自硬件。缺失、过期或未知范围明确显示，不把目标转速当成实测读数。

更凉快每档绝对增加 2 个散热需求百分点，+10 增加 20pp，上限 100%。例如原需求 50% 变为 70%，20% 变为 40%；更安静与默认沿用原行为。偏置平滑、硬件边界、RPM 变化限制与紧急保护保持。高档位可在空闲时保持主动散热：+6～+10 可主动接管，+3～+5 可保留已接管状态；恢复默认可随冷却交还系统。

菜单栏松开偏好滑杆后保存，等待工作线程确认；失败与失联恢复已保存值。智能散热页保留原保存方式，其他风扇模式不因偏好保存而改变。

268 项模拟测试、原生中英文 64 场景布局与隔离交互通过；用户明确授权本轮跳过真实桌面键盘、VoiceOver、窗口交互和材质观察；这些项目保持未验证，不计为通过。未安装或替换用户 App/helper，没有真实风扇写入或温度/噪声效果承诺。Widget 不包含在本版本。正式发行的签名、公证、更新源与提交 CI 以最终发布核验为准。
