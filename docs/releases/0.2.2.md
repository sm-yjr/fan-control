# Fan Control 0.2.2

本版本修复传感器适配和 Smart Cooling 热负荷状态处理，并补充诊断状态导出。

## 修复与改进

- 完善 Apple Silicon M1–M5 已知温度节点的适配，覆盖 Mac mini、Mac Studio、MacBook Pro、MacBook Air 四类机型；MacBook Air 无风扇时保持仅监测，禁止风扇写入。
- 修复运行中超过 15 秒的采样中断会将已经建立的热负荷归零的问题，恢复采样后继续沿用已建立的热负荷状态。
- 增加热点温度的保守散热下界，热点温度升高时保持必要的散热余量。
- 紧急保护解除后的降速按 35 RPM/s 渐变，避免温度或系统热压力刚跨过阈值就突然降速；紧急升速仍立即执行。
- 诊断导出新增 `desired_rpm`、`confirmed_target_rpm`、`reason`、`pending`、`last_failure`、`safety_override`、`safety_failure` 和 `takeover_hold_secs`，便于区分目标值、确认值、等待状态与失败状态。

## 候选验证

- `./script/test_rust.sh` 已通过 229 项测试、rustfmt 和 Clippy；`MACOSX_DEPLOYMENT_TARGET=14.0 cargo build --locked` 已通过。
- 0.2.2/build 202 候选包为 arm64、最低系统版本 14.0；App 与 App 外独立 helper 均通过严格 ad-hoc 签名检查，helper 的 `otool -L` 未发现 bundle 内动态库依赖。Stats 原文已随包保存。
- `test_update_runtime.sh` 及候选包自身的 Sparkle probe 已通过。
- 在 Mac Studio M1 Ultra 执行只读 `--read-sensors` 通过，识别 2 个风扇、12 个 CPU 温度读数和 4 个 GPU 温度读数，无警告。
- M4 模型仿真使用同一份用户温度和负载数据及 1000–4900 RPM 硬件范围，0.2.2 的稳态目标为 2844 RPM，0.2.1 为 1724 RPM；修复后的传感器映射与模型纳入了 `TCMb` 平均值 66.606°C 和 `TCMz` 最高值 81.828°C。

## 验证边界

- 上述结果不代表实机噪声或性能优于系统默认的结论。
- 尚未完成各型号的真实硬件写入验收，也尚未完成真实睡眠—唤醒验收。
- 只读传感器证据覆盖 Mac Studio M1 Ultra；其他机型的硬件行为仍需按产品验收清单单独确认。
- 正式包的签名、公证、DMG、Sparkle appcast 及更新链路以本版本发布工作流的实际结果为准。
