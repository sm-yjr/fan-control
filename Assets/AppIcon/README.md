# Fan Control App Icon

`FanControlAppIcon-Source.png` is the 1024×1024 full-square source artwork used
for macOS packaging. It intentionally has no pre-rendered corner radius,
border, or outer tile shadow because macOS applies the final app-icon mask.

`FanControl.icns` contains the packaged icon representations from 16×16 through
1024×1024. `FanControlLogo.png` is the rounded presentation preview and is not
copied into the app bundle.
